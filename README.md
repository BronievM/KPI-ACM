### 📌 Нагадування

**У КПІ Ми підтримуємо [академічну доброчесність](https://kpi.ua/academic-integrity)**, тому просимо використовувати ці матеріали відповідально. Виконання робіт із використанням чужих результатів може розцінюватися як порушення [кодексу академічної доброчесності](https://kpi.ua/academic-integrity).

Автор не несе відповідальності за можливі наслідки використання матеріалів третіми особами, включно з анулюванням балів або іншими академічними санкціями у випадках порушення Кодексу честі, зокрема:
> 3.2.1 Академічний плагіат  
> 3.2.4 Фальсифікація  
> 3.2.5 Списування
